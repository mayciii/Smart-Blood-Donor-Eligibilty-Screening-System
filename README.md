# 🩸 Smart Blood Donor Eligibility Screening System

> **Academic Project** — Data Structures & Algorithms (DSA) | Bachelor of Science in Information Technology (2025)

---

## 📌 Project Overview

The **Smart Blood Donor Eligibility Screening System** is a desktop application developed using **Python** and **Tkinter**. Built as a DSA course requirement, this project demonstrates how algorithmic logic and decision trees can be applied to a real-world medical screening scenario.

The system automates the process of evaluating blood donor eligibility based on medical and health-related criteria — reducing manual errors, speeding up the screening process, and assisting medical personnel in making faster, more accurate decisions.

> ⚠️ **Note:** This is an academic prototype developed for educational purposes only. It does **not** replace or substitute professional medical evaluation.

---

## 🎯 Objectives

- Digitize the blood donor screening process
- Automatically validate donor information using structured logic
- Determine eligibility through programmed decision-making rules
- Provide a user-friendly graphical interface (GUI)
- Demonstrate DSA concepts applied to a practical use case

## ✨ System Features

- 🖥️ Graphical User Interface (GUI) built with Tkinter
- 📋 Donor information input form
- ✅ Input validation (age, weight, health conditions, etc.)
- ⚕️ Risk factor assessment module
- 🔍 Automatic eligibility checking engine
- ⚡ Instant result display — **Eligible** or **Not Eligible**

---

## ⚙️ How the System Works

```
Step 1 → User enters donor information into the form
Step 2 → System validates all input data
Step 3 → Health conditions and risk factors are evaluated
Step 4 → Eligibility rules (decision logic) are applied
Step 5 → System displays the final result
          ├── ✅ Eligible to Donate
          └── ❌ Not Eligible to Donate
```

---

## 🩺 Sample Eligibility Criteria

The system evaluates the following parameters:

- **Age** — Must meet the minimum/maximum age requirement
- **Weight** — Must meet the minimum weight threshold
- **Medical Conditions** — Checks for disqualifying illnesses
- **Recent Illnesses** — Evaluates recent health history
- **High-Risk Behaviors** — Screens for deferral-worthy activities
- **Other Health Restrictions** — Additional medical filters

## 🚀 How to Run the Project

### Prerequisites
- Python 3.x installed on your machine

### Steps

```bash

# 2. Navigate to the project folder
```
